## FASE 1 — Correcciones inmediatas AXXIS (Semanas 1-2)

> Objetivo: versión V2 del media kit AXXIS lista para usar por el equipo comercial

### 1.1 Datos que completar antes de imprimir/distribuir
- [ ] **Agregar métricas web reales:** sesiones mensuales, usuarios únicos, tiempo en página — fuente: Google Analytics. Si no están disponibles, marcar como [PRÓXIMAMENTE] en lugar de omitir.
- [ ] **Aclarar el tiraje actual con contexto:** no ocultar la caída de 18.000 a ~5.000-7.000 ejemplares — contextualizarla: "circulación auditada + distribución segmentada al gremio de arquitectura y diseño". Un tiraje pequeño y preciso es más vendible que uno grande e inflado.
- [ ] **Completar precios de AXXIS Invita y En la Historia de…** — están sin precio visible, lo que genera fricción en el proceso de venta.
- [ ] **Añadir alcance mínimo garantizado por formato digital** — cuántas impresiones/clics asegura cada paquete (Newsletter: 47K contactos, apertura 25%. Tours: X reproducciones. Cubrimiento: 11 salidas).

### 1.2 Sección nueva: Casos de Éxito
Referente: ningún competidor omite esta sección.
- [ ] Seleccionar 2-3 anunciantes actuales que autoricen aparecer (KEVINS JOYEROS, LAMITECH, TECNOGLASS son los de mayor ticket — ver [[AXXIS]])
- [ ] Formato por caso: logo + nombre de marca + formato comprado + resultado obtenido (impresiones, clics, leads, ventas atribuidas si las tienen)
- [ ] Si no hay métricas de resultado, usar cotización editorial: "X marca eligió AXXIS para su lanzamiento de…"

### 1.3 Sección nueva: Bundles (impreso + digital + redes)
Esta es la oportunidad comercial más grande y no está en el media kit actual.
- [ ] Diseñar 3 paquetes combinados:
  - **Bundle Presencia:** página corriente + billboard web + 1 post redes ($X)
  - **Bundle Autoridad:** páginas interiores + Tour AXXIS + newsletter + 2 posts redes ($X)
  - **Bundle Impacto:** formato de alto impacto + video + cubrimiento + newsletter + redes ($X)
- [ ] Definir precios con Catalina — aplicar descuento por paquete vs. suma de formatos individuales
- [ ] Incluir en el media kit como slide dedicada con los 3 paquetes

### 1.4 Ajuste de propuesta de valor editorial
Slide 3 actual ("¡Inspirando a Colombia con la revista AXXIS!") es genérica.
- [ ] Reescribir con 3 diferenciadores concretos vs. competencia digital:
  1. **Audiencia verificada de profesionales** (no usuarios anónimos)
  2. **35 años de autoridad editorial** — el gremio de arquitectura confía en AXXIS
  3. **Plataforma completa** — impreso + digital + redes + eventos + podcast

### 3.2 Media Kit por segmento de anunciante (60-90 días)
Un solo media kit genérico pierde efectividad. Crear versiones específicas:
- [ ] **AXXIS — Materiales y Construcción** (target: CORONA, LAMITECH, TECNOGLASS, ACESCO)

- [ ] **Diners — Cultura y Entretenimiento** (target: museos, festivales, plataformas de streaming)
- [ ] Diferencia: cada versión arranca con la audiencia y contexto editorial más relevante para ese sector

### 3.3 Versión "one-pager" ejecutivo (30 días)
- [ ] Una sola página A4/carta con: propuesta de valor + audiencia (1 dato clave) + top 3 formatos + contacto
